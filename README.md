# مبيعات علي العراب

نظام مبيعات متكامل لمحل هواتف: **بيع أجهزة وإكسسوارات، صيانة، خطوط وخدمات (آسياسيل / زين العراق)، ديون، وتوافقات لاصقات الحماية**.
تطبيق أندرويد (موبايل وتابلت) يعمل **بدون إنترنت**، وكل البيانات محفوظة على الجهاز.

## تحميل التطبيق

كل تعديل يُرفع على فرع `main` يبني ملف APK تلقائياً عبر GitHub Actions.
حمّل آخر نسخة من صفحة **[Releases](../../releases/latest)** ← ملف `alarab-v1.0.X.apk` ← ثبّته على الجهاز.

## الأقسام

| القسم | ماذا يفعل |
|---|---|
| **الرئيسية** | مبيعات اليوم، المقارنة مع أمس، عمليات سريعة، رسم بياني لآخر 7 أيام، آخر العمليات |
| **نقطة البيع** | سلة مشتريات، زر **عدد** لبيع كمية كبيرة مرة واحدة، مسح الباركود بالكاميرا أو بالقارئ، خصم، بيع نقدي أو **آجل** (يتحول ديناً تلقائياً)، إيصال |
| **الخطوط والخدمات** | واجهتان: **الخدمات** و**الخطوط المباعة**. إضافة خط بالاختيار فقط: نوع الخط ← الخدمة (تظهر خدمات النوع المختار فقط) ← المبلغ. ترقيم تسلسلي #1، #2 ... حتى تصفير الشهر |
| **الصيانة** | كل الأجهزة المستلمة من الزبائن وحالتها (مستلم، قيد الصيانة، بانتظار قطعة، جاهز، تم التسليم، تعذر الإصلاح)، وصل استلام، عربون، مراحل الصيانة، فاتورة التسليم، **إبلاغ الزبون بواتساب** أو اتصال مباشر |
| **المخزن** | سجل لكل قطعة: الكمية، الكلفة، السعر، IMEI، الباركود، **سجل حركة** (إضافة/بيع/إرجاع/جرد)، تنبيه النواقص، إضافة الكميات بأزرار سريعة (+10، +50، +100)، منع تكرار IMEI والباركود |
| **الديون والطلبات** | زر **إضافة دين / طلب** ظاهر دائماً أعلى الشاشة. الموظف يضيف فقط؛ التعديل والحذف للمدير. تسجيل دفعات بوصل، **تذكير الزبون بواتساب** |
| **توافقات اللاصقات** | ابحث عن أي جهاز (عربي أو إنجليزي) فتظهر كل الأجهزة التي تركب عليها نفس اللاصقة، مع الكمية المتوفرة بالمخزن |
| **الفواتير** | أرشيف كل الفواتير مع بحث وفلترة، طباعة، مشاركة PDF، **إرجاع مادة** من الفاتورة، إلغاء/تعديل (مدير) |
| **المصروفات** | إيجار، كهرباء، رواتب... لحساب صافي الربح |
| **التقارير** (مدير) | الإيرادات، الربح، صافي الربح، المبيعات حسب القسم، الأكثر مبيعاً، أداء الموظفين، أرشيف الأشهر |
| **الإدارة** (مدير) | الخطوط والخدمات وأسعارها، المستخدمون، معلومات المحل، الطابعة، بوت تليجرام، النسخ الاحتياطي، سجل العمليات، **تصفير الوردية** |

## الصلاحيات

- **الموظف**: يضيف كل شيء (بيع، خط، صيانة، منتج، دين، مصروف).
- **المدير**: وحده يعدّل ويحذف المبيعات والديون والمنتجات. يمكن للمدير الموافقة على عملية من جهاز الموظف بإدخال رمزه.
- كل عملية تُسجل في **سجل العمليات** باسم من نفذها.

## الطباعة

اختيارية بالكامل — بدون طابعة يعمل البرنامج طبيعياً ويمكن مشاركة الفاتورة PDF.
- **طابعة بلوتوث حرارية 58/80 مم**: اقرنها من إعدادات بلوتوث الجهاز ثم اخترها من الإدارة ← الطابعة. العربية تُطبع بشكل صحيح لأن الإيصال يُرسل كصورة.
- **طباعة النظام**: لطابعات الواي فاي / USB عبر خدمة الطباعة في أندرويد.
- خيار **طباعة تلقائية** بعد كل بيع.

## بوت تليجرام

من الإدارة ← بوت تليجرام: أنشئ بوت من `@BotFather`، الصق الرمز، أرسل للبوت رسالة، ثم اضغط "جلب المعرّف تلقائياً".
يصلك إشعار بنوع البيع وسعره عند كل عملية مؤكدة. إذا انقطع الإنترنت تُحفظ الرسائل وتُرسل لاحقاً تلقائياً.
يمكن أيضاً إرسال **نسخة احتياطية** كاملة إلى تليجرام.

## مفتاح التوقيع (مهم للتحديثات)

حتى تُثبَّت النسخ الجديدة فوق القديمة **بدون حذف البيانات** يجب أن تُوقّع كل النسخ بنفس المفتاح.
- تلقائياً: أول بناء يُنشئ مفتاحاً ويحفظه في ذاكرة GitHub Actions الخاصة بالمستودع (تُحذف إذا لم يُبنَ المشروع لمدة 7 أيام).
- **الطريقة الدائمة (موصى بها)**: أنشئ مفتاحاً وضعه في *Settings ← Secrets and variables ← Actions*:

```bash
keytool -genkeypair -keystore alarab.jks -alias alarab -keyalg RSA -keysize 2048 -validity 10000
```

```bash
base64 -w0 alarab.jks
```

ثم أضف الأسرار: `ALARAB_KEYSTORE_BASE64` (ناتج الأمر الثاني)، `ALARAB_KEYSTORE_PASSWORD`، `ALARAB_KEY_ALIAS` (`alarab`)، `ALARAB_KEY_PASSWORD`. احتفظ بملف `alarab.jks` في مكان آمن.

## تصفير الوردية

زر **تصفير الوردية** في الشاشة الرئيسية والإدارة (للمدير): يعرض ملخص الوردية (المبيعات، المستلم، المصروفات، الصافي بالصندوق)،
ثم يبدأ وردية جديدة من 0 د.ع ويرسل تقرير الإغلاق إلى تليجرام. لا يُحذف أي سجل.
